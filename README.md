# VolumeDuPc

Permet de controler le volume du pc a la voix

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Commandes :
- montele volume, baoisse le son, coupele volume, remet le son
- régle/mets le volume à 10%, 20%, 30%, 40%, 50%,.....100%

## Multi-room

The `VolumeDuPc` plugin is fully multi-room.

## Multi-language

The `VolumeDuPc` plugin relies solely on the system's available languages.
